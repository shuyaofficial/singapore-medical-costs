# シンガポール医療費を読み解く

TikTokで紹介された日本の診察・点滴と、シンガポールの手術費用を、診療内容・病院区分・支払制度に分けて説明する日本語HTMLです。確認日：2026年9月5日。

## 閲覧

`index.html` をブラウザで開いてください。外部ライブラリは不要です。出典は本文中に記載しています。

- TikTokの会計16,600円、虫垂炎手術の約500万円という体験談、保険金555万円を区別
- MOHの同じ手術区分の病院別中央値を比較
- SGD／日本円の切替と説明用換算レートの変更
- 背景の雲の動きを停止可能。端末の「視差効果を減らす」設定にも対応

金額は出典の対象年・居住資格・治療範囲によって異なり、個別患者の見積額を示しません。為替の初期値は説明用の仮定です。背景はSVGによる模式図で、動画や生成3Dモデルではありません。
